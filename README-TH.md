# Reality or Fake — ระบบสุ่มของแท้–ของปลอมสำหรับโรลเพลย์

เว็บแอปธีมแฟนตาซีม่วง–ดำ–ทอง สร้างด้วย React + Vite และใช้ Supabase สำหรับประวัติร่วมระหว่างสมาชิก

## โหมดการทำงาน

- **โหมดทดลอง:** เปิดแอปได้โดยไม่ตั้งค่า Supabase แต่ประวัติจะอยู่เฉพาะในเบราว์เซอร์เครื่องนั้น
- **โหมดฐานข้อมูลกลาง:** ตั้งค่า Supabase ตามขั้นตอนด้านล่าง ประวัติการสุ่มจะแชร์กันระหว่างสมาชิกที่เข้าเว็บเดียวกัน และอัปเดตแบบเรียลไทม์

> สำคัญ: ตัวอย่างนี้เป็น starter สำหรับโรลเพลย์สาธารณะ นโยบาย SQL อนุญาตให้ผู้เยี่ยมชมอ่าน/เพิ่มประวัติ และแก้ไขเปอร์เซ็นต์/ลบประวัติได้ จึงไม่เหมาะกับรางวัลมีมูลค่าหรือกลุ่มส่วนตัวจนกว่าจะเพิ่มระบบล็อกอินและสิทธิ์ผู้ดูแล ห้ามนำ Supabase `service_role` key มาใส่ในเว็บแอปเด็ดขาด

## ขั้นตอนติดตั้งบน Android (ทำได้ด้วยมือถือ)

### 1. เตรียมบริการ
1. สมัครบัญชี GitHub และ Supabase
2. สร้างโปรเจกต์ใหม่ใน Supabase
3. เปิด **SQL Editor** → **New query**
4. คัดลอกเนื้อหาไฟล์ `supabase.sql` ทั้งหมดไปวาง แล้วกด **Run**
5. ไปที่ **Project Settings → API** (บางหน้าตาใช้ชื่อ Data API / API Keys) แล้วคัดลอก Project URL และ anon/publishable key

### 2. อัปโหลดโค้ดขึ้น GitHub
1. ดาวน์โหลด ZIP และแตกไฟล์
2. สร้าง repository ใหม่ใน GitHub
3. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดจาก ZIP เข้า repository
4. สร้างไฟล์ `.env` ที่ root โดยคัดลอก `.env.example` แล้วใส่ค่าจริง:
   ```
   VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
   VITE_SUPABASE_ANON_KEY=YOUR_ANON_OR_PUBLISHABLE_KEY
   ```
   ถ้า GitHub บนมือถือสร้างไฟล์ `.env` ได้ไม่สะดวก ให้ใช้การตั้งค่า Environment Variables ในบริการ deploy ตามขั้นตอนถัดไปแทน ไม่ต้อง commit คีย์จริงลง repository สาธารณะ

### 3. เผยแพร่เป็นเว็บแอปฟรี
1. เข้า Vercel แล้วล็อกอินด้วย GitHub
2. กด **Add New → Project** แล้วเลือก repository นี้
3. ใน **Environment Variables** เพิ่ม:
   - `VITE_SUPABASE_URL` = Project URL ของ Supabase
   - `VITE_SUPABASE_ANON_KEY` = anon/publishable key
4. กด **Deploy** และรอจนเสร็จ
5. เปิด URL ที่ Vercel ให้มา เช่น `ชื่อโปรเจกต์.vercel.app`

### 4. เพิ่มลงหน้าจอหลัก Android
1. เปิดลิงก์เว็บแอปใน Chrome
2. กดเมนูจุดสามจุด `⋮`
3. เลือก **เพิ่มลงในหน้าจอหลัก** หรือ **ติดตั้งแอป** (ข้อความอาจต่างกันตามรุ่น)
4. กดเพิ่ม/ติดตั้ง ไอคอนจะปรากฏบนหน้าจอหลัก

## วิธีใช้
1. ใส่ชื่อผู้เล่นและชื่อไอเทม
2. กด **สุ่มไอเทม**
3. ผล “ของแท้” หรือ “ของปลอม” จะแสดงพร้อมบันทึกประวัติ
4. เปิดไอคอนตั้งค่าเพื่อเปลี่ยนอัตราของแท้
5. แชร์ URL ให้สมาชิกคนอื่นใช้เว็บเดียวกัน

## หมายเหตุด้านความปลอดภัยและความถูกต้อง
- ปุ่มสุ่มใช้ `Math.random()` ในเบราว์เซอร์ เหมาะกับกิจกรรมโรลเพลย์ทั่วไป ไม่ใช่การสุ่มที่ตรวจสอบได้หรือป้องกันการโกง
- SQL ตัวอย่างเปิดสิทธิ์สาธารณะเพื่อให้เริ่มทดลองง่าย ชื่อผู้เล่นไม่ใช่การยืนยันตัวตน และทุกคนที่มี URL อาจแก้ค่าเปอร์เซ็นต์หรือลบประวัติได้
- หากต้องการใช้งานจริงในกลุ่มปิด ควรเพิ่ม Supabase Auth, จำกัดการตั้งค่า/ลบประวัติให้ผู้ดูแล และย้ายการสุ่มไปยัง Edge Function/เซิร์ฟเวอร์
- ไม่ควรใช้ระบบนี้ตัดสินความแท้ของสินค้าจริง เป็นระบบสุ่มสำหรับโรลเพลย์เท่านั้น

